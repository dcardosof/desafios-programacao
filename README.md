## Resumo dos Conceitos Praticados

Durante as atividades realizadas no aplicativo Coddy, aprendi conceitos básicos de programação em Python, como o uso de comentários, entrada e saída de dados, criação e utilização de variáveis e operadores matemáticos. Também pude praticar a sintaxe básica da linguagem e entender melhor como o Python realiza cálculos e trabalha com diferentes valores.

As principais dificuldades foram compreender a sintaxe correta dos comandos e utilizar os operadores de forma adequada nas expressões matemáticas. As estruturas mais utilizadas foram as variáveis, os comandos de entrada e saída, os comentários e os operadores matemáticos, como `+`, `-`, `*` e `/`. Essas atividades ajudaram a desenvolver uma base para continuar aprendendo outros conceitos de programação.
